
# TINTEI BEAUTY Kiosk -- Розширення функціоналу

## Що буде зроблено

### 1. Прибрати розділ "Акції"
Видалити пункт "Акції" (promotions) з меню Dashboard.

### 2. Розділ "Зробити термін" (Booking)
Новий екран `/booking` з:
- Іконка майстра -- при натисканні відкривається календар (date picker) для вибору дати
- Вибір часу (time slots)
- Форма: ім'я, прізвище, номер телефону, email
- Кнопка підтвердження

### 3. Розділ "Замовити напій" (Order Drink)
Новий екран `/order-drink` з меню напоїв:
- Кава, Чай зелений, Чай чорний, Чай фруктовий, Капучіно, Латте макіато
- Опція вибору кількості ложок цукру (0-5) для кожного напою
- Кнопка замовлення

### 4. Розділ "Замовити продукт догляду" (Order Product)
Новий екран `/order-product` з продуктами, підібраними під категорію послуги:
- Hair: шампуні, кондиціонери, маски для волосся, олії
- Nails: олія для кутикули, крем для рук, лак-закріплювач
- Makeup: міцелярна вода, крем для обличчя, сироватка
- Sugaring: заспокійливий лосьйон, скраб, зволожуючий крем
- Massage: масажна олія, розігріваючий крем, ролер
- Laser: SPF-крем, заспокійливий гель, зволожуючий крем
- Вибір кількості для кожного продукту

### 5. Розділ "В тренді" (Trending)
Новий екран `/trending` з фото трендів для кожної категорії:
- Використання placeholder-зображень з Unsplash (безкоштовні URL)
- Картки з фото та описом тренду
- Фільтрація за обраною категорією послуг

### 6. Розділ "Обрати вільного майстра" (Choose Master)
Новий екран `/choose-master` з картками майстрів:
- Аватар, ім'я, спеціалізація
- Статус "вільний зараз" (mock-дані)
- Можливість вибору майстра
